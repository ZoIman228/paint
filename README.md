# Paintbox 🎨

Легка адаптивна малювалка на чистих HTML, CSS і JavaScript. Нічого встановлювати не потрібно.

## Як запустити

1. Розпакуй архів.
2. Відкрий `index.html` у сучасному браузері.
3. Малюй мишкою, стилусом або пальцем на сенсорному екрані.

## Що вміє

- Пензель, гумка та піпетка для вибору кольору з полотна.
- Власний колір і палітра швидкого вибору.
- Розмір пензля та непрозорість.
- Заливка й очищення полотна з можливістю скасувати дію.
- Скасування/повторення до 35 кроків.
- Збереження результату в PNG.
- Збільшення полотна колесом миші або жестом двох пальців (pinch), із прив’язкою до курсора/центру жесту.
- Кнопки збільшення та скидання масштабу; масштаб від 100% до 500% (зменшення нижче 100% вимкнено).
- Адаптація для мобільних екранів і HiDPI-дисплеїв.

## Гарячі клавіші

| Клавіші | Дія |
| --- | --- |
| `B` | Пензель |
| `E` | Гумка |
| `I` | Піпетка |
| `G` | Залити полотно поточним кольором |
| `Ctrl+Z` | Скасувати |
| `Ctrl+Y` або `Ctrl+Shift+Z` | Повторити |
| `Ctrl+S` | Зберегти PNG |
| `[` / `]` | Зменшити / збільшити пензель |

## Масштабування полотна

- Колесо миші над полотном — наблизити або віддалити ділянку під курсором.
- Два пальці на сенсорному екрані — наблизити/віддалити та перемістити полотно.
- Кнопка `+` — збільшити масштаб; `Скинути` — повернути 100%.

Проєкт не використовує зовнішні бібліотеки чи мережеві запити.


## Масштабування та переміщення полотна

- Колесо миші — збільшити або зменшити масштаб до 100% відносно курсора.
- Два пальці — масштабувати та переміщати полотно на сенсорному екрані.
- `Space` + перетягування лівою кнопкою — перемістити полотно.
- Середня або права кнопка миші + перетягування — перемістити полотно.
- Кнопка «Скинути» — повернути масштаб і позицію до початкових.

Клітинчастий фон навколо білого аркуша показує межі справжньої області малювання.
